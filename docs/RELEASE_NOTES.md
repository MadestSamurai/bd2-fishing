# BD2 Fishing 0.3.2

- 修复部分钓鱼地图进入后不会自动移动的问题：没有导航网格时，使用游戏原有的角色行走方式靠近钓区，到位后朝向水面续钓。
- 移动停止、受阻和目标等待状态提供更清楚的诊断，避免反复启停却没有移动。
- 保留“只保留上锁鱼”选项；开启后，未上锁的传说鱼也可自动出售。

升级前请关闭旧工具并正常重启游戏，然后连接新版。自动靠近钓区默认开启。

| 版本 | 自带运行库 | 运行要求 |
| --- | --- | --- |
| Portable | 是 | Windows x64，直接打开EXE |
| Lite | 否 | 安装 .NET Desktop Runtime 8 x64 |

两版功能一致，都提供EXE与包含说明、许可证的ZIP。
