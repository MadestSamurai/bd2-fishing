# BD2 Fishing 0.3.1

- 背包满自动出售默认开启，传说鱼、锁定鱼、资料不明鱼拆为三个独立保留开关，默认全部开启。
- 按鱼种保存仅最大、仅最小或两者的保留规则，支持传说／锁定类别，保留规则取并集。
- 取消锁定鱼保留后，调用游戏原生解锁，确认回执与库存锁定状态后重新规划出售；不会直接出售仍锁定的鱼。
- 停止或更改规则取消后续操作；超时暂停，已解锁鱼不会自动还原。
- 扩展本地接口检查，核对体型、原生解锁及本地化鱼名；不包含游戏 DLL。

新版需关闭旧工具并正常重启游戏后连接。

# BD2 Fishing 0.3.0

新增到期前往返换图，并同时提供 Portable 和 Lite 两个版本。

| 下载版本 | 自带 .NET 运行库 | 使用要求 | 功能 |
| --- | --- | --- | --- |
| **Portable**（推荐） | 是 | Windows x64，双击即用 | 全部功能 |
| **Lite 精简版** | 否 | Windows x64，先安装 **.NET Desktop Runtime 8 x64** | 与 Portable 完全相同 |

每个版本都有单 EXE 和包含说明、许可证的 ZIP。Lite 用户可到[微软 .NET 8 下载页](https://dotnet.microsoft.com/download/dotnet/8.0)安装 Windows x64 的 Desktop Runtime，建议使用最新 8.0 补丁；只有基础 .NET Runtime 或 ASP.NET Runtime 不够。两版都无需安装开发 SDK。

- **到期前自动往返换图默认开启**：读取游戏的入场时间、同步时钟和地图时限，剩余 5 分钟时完成当前一竿，再去钓鱼大厅并返回原钓场。
- 返回后须确认新的地图倒计时和可抛竿状态才继续；不修改游戏计时，不提前结束鱼战，也不会将地图 ID 提前变化误判为加载完成。
- 状态区展示地图倒计时与已完成往返次数。可随时关闭该设置；停止钓鱼或关闭工具会取消未发出的后续换图。
- 配合昼夜切换、收获、升级、出售及用饵回执。未解锁原钓场、加载超时或用户中途切到其他地图时暂停并给出诊断，不反复尝试。
- 保留默认 1000 ms 可调间隔、鱼饵使用和满背包自动出售，仍保留全部传说／锁定鱼。

升级前关闭旧工具并正常重启游戏，然后使用任意一个版本点击“连接游戏”和“开始钓鱼”。Portable 与 Lite 使用同一份本机设置，不需要同时运行。
