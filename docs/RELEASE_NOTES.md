# BD2 Fishing 0.2.0

首个独立公开版本，MIT 许可。提供 Windows x64 单 EXE 和包含说明／许可证的 ZIP；无需安装 .NET 或开发工具。

- 保留连续钓鱼、默认 1000 ms 可调间隔、自动鱼饵、满背包出售并保留全部传说／锁定鱼、昼夜切换续接。
- 移除发行包对指定游戏文件 SHA/MVID 的锁定，改为连接时解析接口并自动编译本机适配 Hook。
- 相同契约通过两个真实客户端检查；旧版本自动适配 12 个类型和 58 个成员名称变化。
- 缺失或有歧义的接口停止连接，并写入本机兼容诊断。
- GitHub Actions 支持从公开源码自动测试、构建及发布。仓库／包不含游戏 DLL、账号或私有工作台组件。

验证：13,377 条钓鱼与保护断言、24 项兼容性回归、两个客户端各 50 项接口检查，以及打包后的 WPF 离线检查。新版 Runtime6 的连续实机钓鱼仍待试用，不能将离线检查视为已实机通过。

升级前请关闭旧工具并正常重启游戏，之后点击“连接游戏”和“开始钓鱼”。
