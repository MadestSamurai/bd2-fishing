## 快速开始

**升级前**：暂停并关闭旧工具，正常重启游戏，再打开新版连接。

1. 进入已解锁的钓鱼地图，关闭游戏内自动钓鱼。
2. 打开助手，点击「连接游戏」，等待钓点识别。
3. 检查鱼饵与保留规则，点击「开始钓鱼」。落点离水较远时，默认自动走到可钓区域。
4. 点击「停止钓鱼」或关闭窗口可停止；已开始的这一竿可能通过正常松开回调完成。

## 功能与设置

| 功能 | 默认行为 |
| --- | --- |
| 下一竿间隔 | 1000 ms，支持 0–60000 ms，运行中可修改 |
| 抛竿蓄力 | 90%，支持 5–95% |
| 收线与长按 | 按游戏帧读取真实判定区；优先弱点 |
| 自动靠近钓区 | 默认开启；进图或往返落地后，优先使用现有导航路径；无导航网格时用原生角色行走靠近当前船体钓区，到位转向船外，游戏确认可抛竿后续钓 |
| 背包满自动出售 | 默认开启；背包满后按保留选项出售鱼 |
| 保留全部传说鱼 | 默认开启，独立于其他保留选项 |
| 保留全部锁定鱼 | 默认开启；关闭后仅对待售鱼逐条解锁，确认成功并回读库存后再出售 |
| 保留资料不明的鱼 | 默认开启；关闭后仍不会出售缺少有效鱼表、出售条目或库存 ID 的鱼 |
| 按鱼种保留大小 | 每个鱼种可选不额外保留、仅最大、仅最小、最大和最小；可分别应用于传说鱼、锁定鱼 |
| 自动鱼饵 | 增益到期后使用已有鱼饵一份；增益期间不重复使用，用完继续普通钓鱼 |
| 到期往返 | 默认开启；按游戏剩余时间，提前 5 分钟完成本竿后往返钓鱼大厅与原钓场，确认新倒计时再继续 |
| 昼夜更替 | 完成当前一竿和结算后让游戏正常切图，随后继续 |
| 网络确认 | 等待原始回执并回读库存／增益；超时或失败时暂停，不自动重发 |

可在设置中关闭自动靠近钓区。停止钓鱼、弹窗、场景切换或开始收线时会结束本工具的移动；行走卡住时最多尝试3条路线，仍无法到位会给出原因并暂停。

保留规则取并集：勾选“保留全部传说鱼”时，该类鱼不会因大小规则被出售。若只想保留某鱼种最大／最小的传说鱼，请取消全部传说鱼保留，并为该鱼种设置大小规则。最大／最小在每个鱼种的对应类别内比较；并列时优先保留锁定鱼，再按库存 ID 选择一条；最大与最小相同时保留一条。受大小规则影响的鱼种若缺少体型资料，则该鱼种全部保留。

停止、关闭自动出售或修改保留规则，会取消尚未发出的整理操作。已确认解锁的鱼不会自动重新锁定，状态区显示解锁数量；回执超时或失败会暂停，不自动重发。升级时保留原自动出售偏好；旧版若启用了“只保留上锁鱼”，会继续允许出售未上锁的传说鱼，并保留锁定鱼和资料不明的鱼。全新设置的三个保留开关均默认开启。

不自动购买补给或解锁钓场。往返仅回到原钓场，返回位置由游戏正常入场逻辑安排。关闭往返开关或停止工具会取消尚未发出的返程。停止蓄力会走正常松开回调，可能完成已经开始的这一竿。

## 界面语言

在顶部 **语言 / Language** 中选择简体中文或 English。首次启动跟随系统：中文系统使用简体中文，其他系统使用英语；之后记住手动选择。切换语言不会重启任务或改变设置。游戏提供的名称和图片保持游戏语言，原始诊断保留原文。

维护翻译见 [翻译说明](docs/LOCALIZATION.md)。

## 兼容与限制

支持官方 Windows x64 PC 客户端，一次连接一个游戏进程；工具与游戏需使用相同权限。不支持手机或 Android 模拟器客户端。首次连接会解析本机接口并生成组件，可能需要数秒。无法可靠匹配接口时停止连接并显示原因；跨版本适配不保证所有未来更新都无需维护。

发行包不包含游戏 DLL、资源、账号库或私有采集文件。不调用游戏内自动钓鱼，不购买补给或解锁钓场。

## 诊断与反馈

点击“打开诊断目录”查看 `%LOCALAPPDATA%\BD2Fishing`：

- `compatibility.json`：本次接口适配结果，改名类型／成员数量或失败原因。
- `runtime.json`、`latest.json`：组件状态和最新钓鱼快照。
- `runtime.log`：操作、回执、出售／用饵回读和切图诊断。

这些文件只保存在本机，不会自动上传。报告问题时请先检查文件中的个人信息。其他已注入的 BD2 工具无法随窗口关闭自动卸载；如提示模块冲突，关闭相关工具并正常重启游戏。

反馈时请提供版本、提示文字和相关日志片段，先去除账号、个人路径等信息。不要上传游戏 DLL、完整库存或连接凭据。
